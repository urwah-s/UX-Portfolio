## Design Approach

Across all projects, I follow a consistent, human-centered design process:

1. **Understand Users**  
   Conduct research to identify user needs, pain points, and context

2. **Define the Problem**  
   Translate insights into clear design goals and requirements

3. **Design & Prototype**  
   Create wireframes and prototypes, iterating based on feedback

4. **Evaluate**  
   Use usability testing and analysis to validate and refine solutions
